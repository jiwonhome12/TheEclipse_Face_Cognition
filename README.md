# 창의공간 얼굴인식 출석체크 시스템

동서대학교 창의공간(The Eclipse)의 출입 학생 출결을 **얼굴인식으로 자동 기록**하는 데스크톱 프로그램입니다.
학생이 [출근] / [퇴근] 버튼을 누르고 카메라를 바라보면 얼굴이 확인되는 즉시 출결이 기록됩니다.
기록은 창공시스템(SeatManagerApp)으로 자동 전달되고, 관리자는 주간 출석 시간·일수를 바로 확인할 수 있습니다.

---

## 1. 왜 만들었나

창의공간은 학생이 주 단위로 정해진 시간을 채워야 하는 공간입니다. 기존 방식에는 다음 문제가 있었습니다.

| 문제 | 이 프로그램의 해결 |
| --- | --- |
| 수기 명부·엑셀 정리에 시간이 오래 걸림 | 얼굴인식으로 자동 기록, 엑셀 추출 버튼 제공 |
| 대리 출석(친구가 대신 체크) | 얼굴인식 + 위조판별 + 눈 깜빡임 확인 + 출퇴근 순간 사진 기록 |
| 사진을 들이대는 방식의 부정 출석 | MediaPipe 깜빡임 검사로 차단 |
| 학생이 자기 이수 시간을 알기 어려움 | 출퇴근 직후 [출석 조회]로 본인 일수·시간·부족분 확인 |
| 창공시스템과 출결 데이터가 따로 놈 | 파일 연동으로 명단·출결 자동 동기화 |

## 2. 무엇을 연동했나

| 기술 | 쓰는 곳 |
| --- | --- |
| **InsightFace** (buffalo_l, ONNX Runtime) | 얼굴 검출 + 512차원 임베딩 추출, 코사인 유사도 0.50 이상이면 본인으로 판정 |
| **InsightFace liveness 애드온** (2.0 이상) | 사진·화면 위조 판별. 얼굴마다 실제 사람 점수(0~1)를 매겨 0.8 미만이면 차단 |
| **Google MediaPipe** (`mediapipe.tasks` FaceLandmarker) | 눈 깜빡임(blendshape) 검사 — 위조판별 애드온을 못 쓰는 환경의 2차 방어 |
| **OpenCV** | 웹캠 캡처(윈도우 DirectShow / macOS AVFoundation, 640x480 30fps) |
| **Tkinter** | 화면 구성. 모니터 크기에 맞춰 UI 배율 자동 조절 |
| **SQLite** (`faces.db`) | 학생 정보, 얼굴 임베딩, 출결 로그 저장 |
| **창공시스템(SeatManagerApp, C#)** | `roster.json`(명단) 읽기 / `attendance.json`(출결) 쓰기 |
| **openpyxl** | 출결 엑셀(.xlsx) 추출 |

### 창공시스템 연동 방식

두 프로그램은 아래 공유 폴더를 통해 파일로 주고받습니다. 설치 경로가 달라도 항상 같은 위치를 씁니다.

```
%USERPROFILE%\SeatManagerApp\face-integration\
├── roster.json       창공시스템 → 얼굴인식 (학생 명단, 학생 등록 시 자동 입력)
└── attendance.json   얼굴인식 → 창공시스템 (출근/퇴근 기록, 출결 처리할 때마다 갱신)
```

## 3. 출결 인정 규칙

- **주 20시간 이상, 주 3일 이상** (월요일~일요일 기준)
- **06:00 ~ 24:00** 사이에 찍은 출근/퇴근만 인정 (00:00~06:00 기록은 남지만 인정되지 않음)
- **퇴근까지 찍어야 시간이 인정**됨. 출근만 찍은 날은 출근 일수만 인정
- 하루에 여러 번 출퇴근 가능. 출근→퇴근 한 쌍마다 시간을 더함
- 퇴근하지 않은 상태에서 다시 출근을 누르면 `이미 출근 완료 되었습니다` 안내 후 기록되지 않음
- 기준에 못 미친 부족 일수·시간은 학생 화면에 **빨간색**으로 표시

## 4. 부정 출석 방지

네 단계로 막습니다. 1~3은 모두 통과해야 기록되고, 4는 사후 확인용입니다.

1. **얼굴인식** — 등록된 학생이 0.6초 이상 계속 인식되어야 함 (뒤에 지나가는 사람 오인식 방지)
2. **위조판별 (InsightFace liveness 애드온)** — 얼굴마다 실제 사람 점수를 매겨, 사진이나 휴대폰 화면이면
   출결·학생 등록을 차단합니다. 카메라 상태바에 `⛔ 사진/화면으로 판단됨`이 표시됩니다.
3. **눈 깜빡임 확인 (MediaPipe)** — 최근 10초 안에 눈을 감았다 뜬 적이 있어야 진행됩니다.
   위조판별 애드온을 못 쓰는 환경(인터넷 없음, 구버전 등)에서의 2차 방어입니다.
   깜빡임은 **인식된 얼굴 영역에서만** 검사합니다. 화면 전체로 보면 사진을 들고 있는 사람의 깜빡임이
   대신 잡혀 사진이 통과하기 때문입니다.
4. **출퇴근 사진** — 기록되는 순간의 카메라 화면을 320x240 JPEG(장당 수 KB~15KB)로 저장합니다.
   관리자 화면 [전체 출결로그]에서 📷 표시된 행을 더블클릭하면 볼 수 있고, **90일이 지나면 자동 삭제**됩니다
   (출퇴근 시간 기록은 남음). 학생을 삭제하면 그 학생의 사진도 함께 지워집니다.

> 위조판별 모델은 처음 실행할 때 `~/.insightface/addons/liveness.onnx`로 자동 다운로드되고 SHA256로 검증됩니다.
> 모드는 `observe`라서, 가짜로 판정돼도 얼굴 인식 자체는 계속하고 안내 문구를 띄웁니다.

## 5. 화면 구성

- **메인 화면** — [출근] / [퇴근] 버튼만 표시. 대기 중에는 카메라가 꺼져 있습니다 (카메라 불도 꺼짐)
  - 상단 작은 버튼: **[📋 출석 조회]** (카메라 영상 없이 얼굴로 본인 확인 → 본인의 이번주 출근 시간 표시, 출퇴근 기록 안 함),
    **[📷 카메라 테스트]** (얼굴 인식이 안 될 때 카메라·인식 상태만 확인, 기록 안 함, 60초 뒤 자동 종료),
    **[🔑 관리자]** (로그인 창)
- **출근/퇴근을 누르면** 카메라가 뒤에서만 켜집니다. **화면에는 카메라 영상 없이** 안내 카드(얼굴 확인 중 · 눈 깜빡임 안내)만 뜨고,
  얼굴이 확인되면 자동 기록 후 카메라가 꺼집니다. 카메라 영상은 [카메라 테스트]·관리자 화면에서만 보입니다.
  30초 안에 확인되지 않거나 오른쪽 위 나가기 아이콘을 누르면 메인 화면으로 돌아갑니다.
- **결과 화면** — `OOO 학생 출근 되었습니다.` 10초 뒤 저절로 메인 화면으로 돌아갑니다.
- **[출석 조회]** — 얼굴로 본인 확인 후 이번주 출근 일수·시간·부족분, 오늘 출근 시간,
  패널티, 이번주 출퇴근 기록이 표시됩니다. 20초 뒤 자동으로 닫힙니다.
  (다른 학생이 내 출퇴근 시간을 보지 않도록 메인 화면에는 누구의 시간도 띄우지 않습니다)
- 좌측 상단 로고를 누르면 어느 화면에서든 메인 화면으로 돌아갑니다.
- **관리자 화면** (로그인 후, 나갈 때는 좌측 상단 로고)
  - 학생 현황/수정 — 이름·전공·전화번호·학년·패널티 수정, 체크한 학생 삭제, 명단 새로고침, 출석 엑셀 추출
  - 학생 등록 — 구글폼 학생 명단에서 골라 학번·이름·전공·전화번호를 자동 입력한 뒤 카메라로 얼굴 등록 (이 탭에서만 카메라가 켜짐)
  - 전체 출결로그 — 기간 직접 선택 · 월 단위 · 최근 7일 합계, 주 3회·20시간 충족자 조회, 행 더블클릭으로 출퇴근 사진 보기
  - 설정 — 화면별 메인 복귀 시간(5초 단위, 5~60초), 메인 화면 버튼 크기, 화면 키보드, 카메라 장치, 구글폼 학생 명단 주소
    - 구글폼 학생 명단 (둘 중 하나)
      - **Sheets API (실시간, 추천)**: Google Cloud에서 서비스 계정을 만들고 JSON 키를 받아 [설정] → **서비스 계정 키**에서 고른다.
        응답 시트의 [공유]에 그 서비스 계정 이메일을 **뷰어**로 추가하고, 응답 시트 주소(`…/spreadsheets/d/…/edit`)를 넣는다.
        [학생 등록] 탭이 열려 있는 동안 15초마다 다시 읽어서 새 응답이 바로 보인다. 키 파일(`google_service_account.json`)은 git에 올리지 않는다.
      - **CSV 게시**: 응답 시트에서 **파일 → 공유 → 웹에 게시 → CSV**로 게시한 주소를 넣는다. 주소를 아는 사람은 명단을 볼 수 있으니 주의한다.
      - 열 제목에 "학번"·"이름"(필수), "전공"·"전화"·"학년"이 들어 있으면 알아서 찾는다 ("2학년"은 2로 저장). 비워 두면 창공시스템 명단(roster.json)을 쓴다.

## 6. 설치 및 실행 (다른 PC 포함)

### 가장 쉬운 방법 — exe 설치판 (파이썬 설치 필요 없음)

1. GitHub 저장소의 **[Releases]** 에서 최신 **`TheEclipseAttendance-windows.zip`** 을 내려받습니다.
2. `C:\TheEclipseAttendance` 같은 폴더에 압축을 풀고 **`install.bat`** 을 더블클릭합니다.
   ("Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행])
   - 얼굴 인식 모델(약 300MB)을 처음 한 번 내려받고, 카메라·얼굴 인식 **자가진단 결과**를 보여줍니다.
   - 매일 06:00 자동 실행, 00:00 자동 종료, 로그인 시 자동 실행, 바탕화면 바로가기를 설정합니다.
3. 바탕화면의 **[창의공간 출석체크]** 로 실행합니다.

> InsightFace 얼굴 모델(buffalo_l)은 비상업 연구용 라이선스라 zip에 넣지 않고, 처음 실행할 때 공식 주소에서 받습니다.
>
> **새 배포판 만들기:** `powershell -ExecutionPolicy Bypass -File packaging\build_release.ps1` 로
> `dist\TheEclipseAttendance-windows.zip` 을 만든 뒤, GitHub [Releases] → [Draft a new release] 에 올립니다.
> 태그만 올리면 자동으로 빌드되게 하려면 [packaging/github-actions/release-windows.yml](packaging/github-actions/release-windows.yml) 을
> `.github/workflows/` 로 옮기세요.

### 소스로 설치하기 — 윈도우 무인 운영 PC (파이썬 사용)

매일 **06:00에 자동으로 켜지고 00:00에 자동으로 꺼지는** 출석 PC로 설치합니다.

1. **내려받기** — 둘 중 하나
   - GitHub 저장소 페이지에서 **[Code] → [Download ZIP]** 을 누르고, 압축을 원하는 폴더에 풉니다.
   - 또는 Git이 있으면 `git clone https://github.com/jiwonhome12/TheEclipse_Face_Cognition.git`
     (나중에 `windows\update.bat` 으로 최신 버전을 바로 받을 수 있어서 이쪽을 권장)
2. 폴더 안의 **`windows\install.bat`** 을 더블클릭합니다.
   - 파이썬이 없으면 설치할지 묻습니다 (winget으로 Python 3.12 설치)
   - 필요한 패키지와 얼굴 인식 모델(약 300MB)을 내려받습니다 (처음 한 번, 몇 분 걸림)
   - 작업 스케줄러에 **매일 06:00 자동 실행**을 등록하고, **로그인할 때 자동 실행**, **바탕화면 바로가기**를 만듭니다
3. 바탕화면의 **[창의공간 출석체크]** 로 바로 실행해 보고, 관리자 계정(1234 / 1234)을 바꾼 뒤 학생을 등록합니다.

| 파일 | 하는 일 |
| --- | --- |
| `windows\install.bat` | 설치 + 자동 실행 등록 (다시 실행해도 안전) |
| `windows\update.bat` | GitHub에서 최신 버전 받기 (git clone으로 받은 경우) |
| `windows\uninstall.bat` | 자동 실행·바로가기만 삭제 (학생 DB·사진은 그대로) |

- 06:00에 PC가 꺼져 있었으면 켜고 로그인할 때 실행됩니다. 00:00~06:00에는 자동으로 켜지지 않습니다.
- 자정이 되면 프로그램이 스스로 종료합니다. 관리자가 작업 중이면 로그아웃할 때까지 기다립니다.
- 이미 켜져 있으면 두 번 실행되지 않습니다.
- 콘솔 창 없이 실행되므로, 오류 기록은 `logs\app.log` 에 남습니다.
- 24시간 켜두는 노트북은 전원 설정에서 **절전·화면 끄기 '안 함'**, 제조사 앱에서 **배터리 충전 한도(80% 등)** 를 켜두세요.

### 직접 실행하기

**준비물:** Windows 또는 macOS, Python 3.10 이상, 웹캠, 최초 1회 인터넷 연결

```bash
pip install -r requirements.txt
```

```bash
python attendance_app.py
```

처음 실행할 때 자동으로 준비되는 것들입니다.

- **InsightFace 모델(buffalo_l)** — `~/.insightface/models`에 자동 다운로드 (약 300MB, 최초 1회)
- **위조판별 모델(liveness.onnx)** — `~/.insightface/addons`에 자동 다운로드 (최초 1회). insightface 2.0 이상 필요
- **깜빡임 검사 모델(`face_landmarker.task`)** — 프로젝트 폴더에 자동 다운로드 (약 3.7MB, 최초 1회).
  저장소에 파일이 같이 있으면 그대로 사용합니다. 인터넷이 없어 받지 못하면 **깜빡임 검사만 꺼진 채로** 정상 실행됩니다.
- **`faces.db`** — 없으면 새로 만들고, 기본 관리자 계정(아이디 `1234` / 비밀번호 `1234`)을 생성합니다.

DB와 모델은 `attendance_app.py`가 있는 폴더를 기준으로 찾으므로, 어느 폴더에서 실행해도 동작합니다.

### macOS에서 실행할 때

같은 코드가 윈도우와 맥에서 그대로 돌아갑니다. 맥에서는 아래가 자동으로 바뀝니다.

- 웹캠은 AVFoundation으로 열고, 처음 실행하면 카메라 권한을 묻는 창이 뜹니다. 허용하면 바로 켜집니다.
- 얼굴 인식은 CoreML로 돌려서 CPU보다 약 2배 빠릅니다.
- 글꼴은 맑은 고딕 대신 애플 SD 산돌고딕 Neo를 쓰고, 버튼 색은 윈도우와 같게 나옵니다.

**터미널.app에서 실행하세요.** 카메라 권한은 파이썬을 실행한 앱에 주어집니다.
VS Code 등 다른 앱에서 실행하면 그 앱에도 권한이 있어야 합니다.
권한 창이 안 뜨고 카메라가 꺼져 있으면 **시스템 설정 → 개인정보 보호 및 보안 → 카메라**에서 터미널을 켜고,
터미널을 완전히 종료(⌘Q)한 뒤 다시 실행합니다.

### 라즈베리파이에 설치하기

**준비물:** 라즈베리파이 4 또는 5 (메모리 4GB 이상 권장), **64비트** 라즈베리파이 OS(데스크톱 버전),
USB 웹캠 또는 라즈베리파이 카메라 모듈, 인터넷 연결, 여유 공간 3GB 이상

**① 윈도우 PC에서 — USB에 담기**

USB를 꽂고 `raspberrypi\make_usb_bundle.bat`을 더블클릭합니다.
USB에 `TheEclipse_RaspberryPi` 폴더(약 4MB)가 만들어집니다. 실행에 필요한 파일과 **출결 기록(`faces.db`)·출퇴근 사진**만 담고,
저장소의 InsightFace 원본 소스와 `.git`은 뺍니다. 출석체크 프로그램은 먼저 닫아 주세요(기록 중인 DB가 깨지지 않게).

**② 라즈베리파이에서 — 설치**

USB를 꽂고 파일 관리자에서 `TheEclipse_RaspberryPi` 폴더를 연 뒤, **F4**(현재 폴더에서 터미널 열기)를 눌러 한 줄만 입력합니다.

```bash
bash raspberrypi/install.sh
```

USB(FAT32/exFAT)에서는 가상환경을 만들 수 없어서, 설치 스크립트가 먼저 **홈 폴더(`~/TheEclipse_Face_Cognition`)로 복사**한 뒤
그 자리에서 설치를 이어갑니다. 설치가 끝나면 USB를 뽑아도 됩니다.
나중에 새 버전을 같은 방법으로 옮기면 프로그램 파일만 바뀌고, **라즈베리파이에 쌓인 출결 기록은 덮어쓰지 않습니다.**
(`git clone`으로 받은 경우에는 그 폴더에서 바로 같은 명령을 실행하면 됩니다.)

설치 스크립트가 아래를 순서대로 처리합니다. 다시 실행해도 안전합니다.

1. 시스템 패키지 — 파이썬, Tk(화면), 한글 글꼴(나눔고딕), 빌드 도구, 카메라 도구
2. 가상환경(`.venv`)에 파이썬 패키지 설치 — insightface는 라즈베리파이에서 직접 빌드해서 **10~30분** 걸릴 수 있습니다
3. 얼굴 인식 모델 미리 받기 (약 300MB)
4. 로그인하면 자동 실행 + 메뉴(보조 프로그램)·바탕화면 바로가기 등록

윈도우판과 같은 방식으로 운영됩니다. **매일 06:00에 켜지고 자정(00:00)에 스스로 종료**되며, 오류로 꺼지면 잠시 뒤 다시 켜집니다.
기록은 `logs/app.log`에 남습니다.

| 하고 싶은 것 | 명령 |
|---|---|
| 지금 바로 실행 | 메뉴 → 보조 프로그램 → 창의공간 출석체크, 또는 `bash ~/TheEclipse_Face_Cognition/raspberrypi/start.sh` |
| 카메라 모듈(CSI)인데 화면이 안 나올 때 | `THE_ECLIPSE_CAMERA=csi bash ~/TheEclipse_Face_Cognition/raspberrypi/start.sh` |
| 자동 실행·바로가기 해제 | `bash ~/TheEclipse_Face_Cognition/raspberrypi/uninstall.sh` (출결 DB와 사진은 남김) |
| `$'\r': command not found` 오류가 날 때 | 줄바꿈 문제 — `sed -i 's/\r$//' raspberrypi/*.sh` 후 다시 설치 |

- **카메라:** USB 웹캠은 그대로 쓰고, USB 웹캠이 없으면 카메라 모듈을 `libcamerify`로 연결해 씁니다.
- **속도·과부하 대책:** 라즈베리파이는 자동으로 저전력 설정으로 실행됩니다 — 카메라 15fps, 화면에는 초당 10번만
  확대 없이 그리기, 얼굴 분석은 사이사이 쉬면서 낮은 우선순위로 실행. 얼굴 인식 자체는 PC보다 느려서
  기록되기까지 카메라를 1~2초 더 바라봐야 할 수 있습니다. (PC에서 시험: `THE_ECLIPSE_LOW_POWER=1`)
- **카메라가 끊길 때:** 3초간 영상이 안 오면 프로그램이 스스로 카메라를 다시 연결합니다(번호가 바뀐 USB 장치까지 찾음).
  그래도 자주 끊기면 전원 부족일 가능성이 큽니다 — `vcgencmd get_throttled` 결과가 `0x0`이 아니면
  공식 어댑터(라즈베리파이 4: 5V 3A, 5: 5V 5A)를 쓰고 방열을 확인하세요. 설치 스크립트도 이 기록을 확인해 알려줍니다.
- **눈 깜빡임 검사:** 라즈베리파이(파이썬 3.13)에서 쓸 수 있는 mediapipe가 없으면, 얼굴 인식 모델 묶음에 들어 있는
  106점 얼굴 윤곽 모델(2d106det)로 대신 검사합니다. 그 사람의 평소 뜬 눈 크기 대비 얼마나 감겼는지로 판단하고,
  사진을 기울여 얼굴 전체가 납작해지는 것이나 한쪽 눈만 감기는 것은 깜빡임으로 치지 않습니다.
  라즈베리파이는 얼굴 분석 간격이 길어서 안내도 "눈을 천천히 감았다 떠 주세요"로 바꿨습니다.
  PC에서 이 방식을 시험하려면 환경변수 `THE_ECLIPSE_BLINK=landmark`를 주고 실행합니다.
- **기존 출결 데이터 옮기기:** 윈도우 PC의 `faces.db`를 같은 폴더에 복사하면 등록된 학생과 기록을 그대로 씁니다
  (얼굴 인식 모델이 같아서 다시 등록할 필요가 없습니다).
- 무인 운영이라면 **라즈베리파이 설정 → 디스플레이 → 화면 꺼짐(Screen Blanking)**을 꺼 두세요.

> **보안 주의:** 기본 관리자 계정이 `1234` / `1234`입니다. 실제 운영에 쓰기 전에 반드시 변경하세요.
> `faces.db`에는 학생 얼굴 임베딩과 비밀번호가 들어 있으므로 공개 저장소에 올릴 때 주의가 필요합니다.

## 7. 주요 설정값

[attendance_app.py](attendance_app.py) 맨 위에서 바꿀 수 있습니다.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| `THRESHOLD` | 0.50 | 얼굴 동일인 판정 기준 (코사인 유사도) |
| `WEEKLY_REQUIRED_SECONDS` | 20시간 | 주간 필수 출석 시간 |
| `WEEKLY_REQUIRED_DAYS` | 3일 | 주간 필수 출석 일수 |
| `VALID_ATTENDANCE_START` | 06:00:00 | 이 시각 이후 기록만 인정 |
| `LIVENESS_THRESHOLD` | 0.8 | 실제 사람 판정 기준 점수 (낮출수록 통과가 쉬워짐) |
| `LIVENESS_VALID_SECONDS` | 3초 | 출결 전 실제 사람 판정 유효 시간 |
| `BLINK_CLOSED_SCORE` / `BLINK_OPEN_SCORE` | 0.5 / 0.3 | 눈 감음/뜸 판정 기준 |
| `BLINK_VALID_SECONDS` | 10초 | 출결 전 깜빡임 유효 시간 |
| `TIMEOUT_DEFAULTS` | 30초 / 10초 / 20초 | 얼굴 확인(출근·퇴근·출석 조회) / 결과 화면 / 출석 현황 화면이 메인으로 돌아가는 기본 시간. 관리자 [설정] 탭에서 5초 단위(5~60초)로 바꿀 수 있다 |
| `RECOGNIZE_HOLD_SECONDS` | 0.6초 | 같은 학생이 이 시간 동안 계속 인식돼야 기록 |
| `PHOTO_DIR` | `attendance_photos/` | 출퇴근 사진 저장 폴더 |
| `PHOTO_WIDTH` / `PHOTO_JPEG_QUALITY` | 320px / 70 | 사진 해상도·화질 |
| `PHOTO_RETENTION_DAYS` | 90일 | 사진 보관 기간 (지나면 자동 삭제) |
| `INFERENCE_THREADS` | CPU 코어 수 ÷ 3 | 얼굴인식에 쓸 스레드 수 (화면 끊김 방지) |

## 8. 구조

```
attendance_app.py
├── 얼굴인식 전용 프로세스   InsightFace(인식+위조판별) + MediaPipe를 별도 프로세스에서 실행 (UI 끊김 방지)
├── 카메라 스레드            웹캠에서 최신 프레임만 유지
├── DB / 통계 함수           출퇴근 기록, 출근→퇴근 쌍 묶기, 주간·오늘 집계
└── Tkinter UI               메인(출근/퇴근) / 얼굴 확인 / 결과·출석 조회 창 / 카메라 테스트 / 관리자 화면
```

`faces.db` 테이블

- `users` — 학번, 비밀번호, 이름, 전공, 권한(admin/student), 얼굴 임베딩, 패널티
- `attendance_logs` — 학번, 이름, 구분(CHECK_IN/CHECK_OUT), 날짜, 시간, 사진 경로(`attendance_photos/` 기준, 90일 뒤 비움)
