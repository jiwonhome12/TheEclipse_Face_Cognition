창의공간 얼굴인식 출석체크 — 윈도우 설치판
==========================================

파이썬 설치 없이 바로 쓰는 버전입니다.

[설치]
1. 이 zip 압축을 원하는 폴더에 풉니다.
   권장 위치: C:\TheEclipseAttendance  (OneDrive·바탕화면 폴더는 피하세요)
2. install.bat 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
   - 처음에는 얼굴 인식 모델(약 300MB)을 내려받습니다. 인터넷이 연결되어 있어야 합니다.
   - 자가진단 결과(카메라·얼굴 인식)가 화면에 나옵니다. 카메라 앞에 앉아 있어 주세요.
3. 바탕화면의 [창의공간 출석체크] 로 실행합니다.
4. 상단 [관리자] → 아이디 1234 / 비밀번호 1234 로 로그인해 학생을 등록합니다.
   기본 관리자 계정은 운영 전에 꼭 바꾸세요.

[자동 운영]
- 매일 06:00에 자동으로 켜지고 00:00에 자동으로 꺼집니다.
- 06:00에 PC가 꺼져 있었으면, 켜고 로그인할 때 실행됩니다.
- 관리자가 작업 중이면 로그아웃할 때까지 종료를 미룹니다.
- 자동 실행을 끄려면 uninstall.bat 을 실행하세요. (학생 DB·사진은 지워지지 않습니다)

[데이터 위치] (이 폴더 안)
- faces.db            학생 정보·얼굴 정보·출결 기록 — 백업하세요
- attendance_photos\  출퇴근 사진 (90일 뒤 자동 삭제)
- logs\               실행 기록(app.log), 자가진단 결과(selftest.txt)

faces.db 와 attendance_photos 폴더는 지우지 마세요.
